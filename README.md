# Videoflix Project
Videoflix ist eine Full-Stack-Webanwendung, die es Benutzern ermöglicht, Filme und TV-Serien zu durchsuchen, zu streamen und eigene Wiedergabelisten zu erstellen. 
Das Projekt umfasst ein Angular-Frontend und ein Django-Backend, welche zusammenarbeiten, um ein reibungsloses Streaming-Erlebnis zu bieten.

Projektübersicht
Videoflix ist eine Anwendung, die es Benutzern ermöglicht, durch eine umfangreiche Datenbank von Filmen und Serien zu navigieren, Inhalte anzusehen und Wiedergabelisten zu erstellen. 
Die Anwendung unterstützt HLS (HTTP Live Streaming) für Videoübertragungen und bietet eine Benutzeroberfläche zur Interaktion mit der Backend-API.

Technologien
 -Frontend: Angular, Video.js für HLS-Streaming
 -Backend: Django, PostgreSQL, Redis, FFmpeg
 -Datenbank: PostgreSQL
 -Caching und Warteschlangen: Redis für Caching und asynchrone Aufgaben
 -Streaming: HLS mit FFmpeg und Video.js
 -API-Interaktionen: HttpClient (Frontend), Django REST Framework (Backend)

Anforderungen
Frontend:
-Node.js (Version 12.0 oder höher)
-Angular CLI (Version 10.0 oder höher)
-NPM (Version 6.0 oder höher)
Backend:
-Python (Version 3.8 oder höher)
-PostgreSQL (Version 12 oder höher)
-FFmpeg (für Videoverarbeitung)
-Redis (für Caching und Warteschlangen)
